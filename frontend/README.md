# 前端使用说明

## 快速启动

### 1. 确保后端服务运行

```bash
py main.py
```

### 2. 打开前端页面

直接在浏览器中打开 `frontend/index.html`，或使用任意 HTTP 服务器：

```bash
# 使用 Python 内置服务器
cd frontend
py -m http.server 3000

# 然后访问 http://localhost:3000
```

## 功能说明

### 态势显示

- **自动连接**：页面加载后自动连接态势 WebSocket
- **实时更新**：每秒接收飞机位置更新
- **轨迹显示**：显示飞机最近 12 小时的飞行轨迹
- **颜色区分**：
  - 🔵 蓝色：民机
  - 🔴 红色：军机
  - 🟡 黄色：未知

### 任务管理

1. **创建任务**：点击"创建新任务"按钮
2. **选择任务**：从下拉列表选择已有任务
3. **连接任务**：点击"连接任务"开始接收检测数据
4. **目标显示**：
  - 🟣 紫色圆点：检测到的目标
  - 紫色轨迹线：目标运动轨迹

### 交互功能

- **点击标记**：查看详细信息
- **显示控制**：
  - 显示/隐藏民机
  - 显示/隐藏军机
  - 显示/隐藏轨迹

### 统计信息

底部状态栏实时显示：
- 态势飞机数量
- 任务目标数量
- 检测点总数
- 当前帧数

## WebSocket 连接

### 态势数据

```
ws://localhost:8000/api/ws/situation
```

消息格式：
```json
{
  "type": "situation_update",
  "data": {
    "timestamp": "2026-10-26T10:23:00Z",
    "points": [...]
  }
}
```

### 任务数据

```
ws://localhost:8000/api/ws/tasks/{task_id}
```

消息类型：
- `new_frame`：新帧数据
- `target_update`：目标更新
- `task_status`：任务状态变更

## 技术栈

- **地图**：Leaflet 1.9.4
- **WebSocket**：原生 WebSocket API
- **样式**：纯 CSS
- **逻辑**：原生 JavaScript（无框架）

## 浏览器兼容性

- Chrome 90+
- Firefox 88+
- Edge 90+

## 故障排查

### WebSocket 连接失败

1. 确认后端服务已启动
2. 检查浏览器控制台错误
3. 确认 WebSocket URL 正确

### 地图不显示

1. 检查网络连接（需要加载 Leaflet 和地图瓦片）
2. 查看浏览器控制台错误

### 数据不更新

1. 检查 WebSocket 连接状态（顶部状态指示器）
2. 查看浏览器控制台是否有错误
3. 刷新页面重新连接
